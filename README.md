# la_bataille_des_flandres
Le projet de Mathys Sergent sur le sujet de la bataille. 

Avancement.
Séance 1 : J'ai commencé la préparation du jeu, donc globallemment mes étapes étaient créer la classe "Carte" dans l'objectif de pouvoir créer une carte et les comparer, ensuite créer la classe "Paquet" pour créer toutes les cartes du jeu(48) automatiquement, les mélanger puis les distribuer entre les paquets des 2 joueurs. Tout marche sauf la distribution qui témoigne encore un bug. Je note l'idée tant que je l'ai encore, je peu imaginer un jeu à plusieurs joueurs comme extension.
